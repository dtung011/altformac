Switched to Mac? Your shortcuts didn't come with you.

Years of Windows muscle memory, and Office for Mac only meets you halfway.

Alt sequences don't work

On Windows you autofit a column without thinking. On Mac the same keys type odd characters or do nothing.

Built-in KeyTips stop short

Office for Mac's KeyTips can open a dropdown, but not the final letter inside it. You end up reaching for the mouse.

The mouse slows you down

Building a model or cleaning data means hundreds of small commands. Each trip to the ribbon breaks your flow.

What AltForMac does

A small menu-bar app that turns Windows Alt sequences into real Office for Mac commands.

387 sequences

Excel (206), Word (107) and PowerPoint (74), including the final letters inside dropdowns.

Learn as you type

A small HUD shows the keys you typed and the valid next letters. Escape goes back one level.

Private by design

No networking code. It never reads cells, formulas, file names or document content.

Stays out of your way

Option with other keys works as normal. Office's confirmation dialogs stay. It never blocks typing.

Download

Requires macOS 13 (Ventura) or later. The 0.1.0 build is for Apple Silicon; Intel Macs can build from source.

Homebrew

brew install --cask dtung011/altformac/altformac

DMG

Get AltForMac-<version>.dmg from the latest release and drag it to Applications. It is not notarized yet: on first launch, right-click it and choose Open.

From source

git clone https://github.com/dtung011/altformac.git
cd altformac && scripts/package.sh

After installing

  1. In Excel, Word and PowerPoint, open Preferences > Accessibility and turn off the Option-key KeyTips.
  2. Start AltForMac and allow it in System Settings > Privacy & Security > Accessibility.
  3. Allow Automation for each Office app when macOS asks.

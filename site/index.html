What it does

A small menu-bar app. Microsoft's code is never modified or shipped.

Familiar sequences

W V G toggles gridlines, H O I autofits column width, N V inserts a PivotTable.

Three Office apps

Excel (206 sequences), Word (107) and PowerPoint (74). The mappings are plain YAML files you can read and improve.

A guide on screen

A small HUD shows the keys you typed and the valid next letters, so you can learn as you go.

Stays out of the way

Option with another key, such as Option+arrows, works as normal. Destructive commands keep Office's own confirmation dialogs.

Download and install

Requires macOS 13 (Ventura) or later. The 0.1.0 build is for Apple Silicon. Intel Macs can build from source.

Option 1: Homebrew

brew install --cask dtung011/altformac/altformac

Update later with brew upgrade --cask altformac.

Option 2: Direct download

  1. Open the latest release and download AltForMac-<version>.dmg.
  2. Open the DMG and drag AltForMac to Applications.
  3. The app is not notarized yet, so macOS blocks the first launch. Right-click AltForMac in Applications, choose Open, then Open again.

You can check the download against the SHA-256 in the release notes: shasum -a 256 AltForMac-<version>.dmg

Option 3: Build from source

Needs Xcode or the Command Line Tools (xcode-select --install).

git clone https://github.com/dtung011/altformac.git
cd altformac
scripts/package.sh

scripts/package.sh builds dist/AltForMac.app and the DMG.

Set up

Three one-time steps.

  1. Turn off Office's own KeyTips. In Excel, Word and PowerPoint, open Preferences > Accessibility and switch off the Option-key KeyTips. Otherwise both react.
  2. Allow Accessibility. Start AltForMac, then in System Settings > Privacy & Security > Accessibility switch it on. Without this it cannot see or drive the menus.
  3. Allow Automation for each Office app when macOS asks. It is needed for commands that use AppleScript.

The menu-bar icon shows ⌥ when ready and ⌥! when it needs permission or an app was slow to respond.

Privacy

The app is built so it can't phone home or read your work.

  • No networking code at all.
  • Never reads cell values, formulas, file paths or document content. Accessibility is used only for menu, ribbon and focus elements.
  • Keys are inspected only while an Office app is frontmost, held in memory only while a sequence is in progress, and never written to disk.
  • If an app stops responding for 2 seconds, all keys pass straight through. It never blocks typing.

The code is open, so you can check these claims in the source.

FAQ

Why do I need to turn off Office's KeyTips?

Office for Mac has its own Option-key KeyTips. If both are on, both react to the same tap.

Why does macOS block the first launch?

The app is not notarized yet. Right-click AltForMac in Applications, choose Open, then Open again. You only do this once.

Does it work on Intel Macs?

The 0.1.0 download is built for Apple Silicon. On an Intel Mac you can build it from source (Option 3 above).

Why does it need Accessibility permission?

It finds and presses menu and ribbon items through the macOS Accessibility API. It only queries menu, ribbon and focus elements, never document content.

Is it safe for destructive commands?

Yes. Office's own confirmation dialogs still appear. AltForMac never auto-confirms.

A sequence is missing or wrong. What can I do?

Mappings are YAML files in the mappings folder. Open an issue or a pull request on GitHub.

How do I uninstall it?

Quit it from the menu-bar icon, then run brew uninstall --cask altformac or drag it from Applications to the Trash. It installs no background services and writes nothing outside its app bundle. The README lists the optional permission cleanup.

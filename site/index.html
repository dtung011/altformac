Why you need it

Alt sequences do nothing on Mac

Years of Windows muscle memory, and on a Mac the same keys type odd characters instead.

Office's own KeyTips stop short

They can open a dropdown but not choose the item inside it, so you reach for the mouse anyway.

The mouse slows down real work

A model or a data clean-up is hundreds of small commands. Every trip to the ribbon breaks your flow.

What you get

387 sequences

Excel 206, Word 107, PowerPoint 74, including the final letters inside dropdowns.

A guide as you type

The HUD lists the valid next letters. Escape goes back a level, Backspace removes a letter.

Private

No networking code at all. It never reads cells, formulas, file names or document text.

Safe

Office's confirmation dialogs stay. Option with other keys works as normal. It never blocks typing.

Download

Needs macOS 13 (Ventura) or later. The download is built for Apple Silicon; Intel Macs can build from source.

DMG

Download AltForMac.dmg, open it and drag AltForMac to Applications.

It is not notarized yet: the first time, right-click it in Applications and choose Open.

Homebrew

brew install --cask dtung011/altformac/altformac

From source

git clone https://github.com/dtung011/altformac.git
cd altformac && scripts/package.sh

After installing

  1. In Excel, Word and PowerPoint, open Preferences > Accessibility and turn off the Option-key KeyTips.
  2. Start AltForMac and allow it in System Settings > Privacy & Security > Accessibility.
  3. Allow Automation for each Office app when macOS asks.
Uninstall
  1. Quit AltForMac from its menu-bar icon.
  2. Remove the app. Installed with Homebrew: run brew uninstall --cask altformac (add --zap to also remove its support files). Installed from the DMG or source: drag AltForMac from Applications to the Trash.
  3. Remove its permissions (optional). In System Settings > Privacy & Security, open Accessibility and Automation, select AltForMac and click the minus button.
  4. Turn Office's KeyTips back on if you want them: Preferences > Accessibility in Excel, Word and PowerPoint.

AltForMac installs no background services and writes nothing outside its app bundle, so there is nothing else to clean up. If you added it to Login Items, remove it there too.

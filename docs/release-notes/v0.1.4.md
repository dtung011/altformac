## AltForMac 0.1.4

Windows-style Alt key sequences for Excel, Word and PowerPoint on Mac. Tap Option, type `W V G`, and it
runs, including the last letter inside dropdowns that Office for Mac's own KeyTips leave out.

This release adds key badges on the ribbon, like the KeyTips in Windows Office.

### Download

- **Homebrew:** `brew install --cask dtung011/altformac/altformac`
- **Direct:** download `AltForMac-0.1.4.dmg` below, open it and drag AltForMac to Applications.
  The app is not notarized yet, so macOS warns that it cannot verify it. Click **Done**, then in System Settings >
  Privacy & Security click **Open Anyway** next to AltForMac. (macOS 13 and 14: right-click the app and choose **Open**.)

SHA-256 of the DMG: `b2ff08eab1e86c6b0fe2eaba90e4e827c8d38480f3b33b168092558e1ebfc5ba`

Requires macOS 13 (Ventura) or later. This build is for Apple Silicon.

### Set up (two minutes)

1. In Excel, Word and PowerPoint, turn **off** the Option-key KeyTips (Preferences > Accessibility),
   otherwise both react.
2. Open AltForMac. In System Settings > Privacy & Security > Accessibility, allow it.
   **Updating from an earlier version?** The old switch no longer applies: select AltForMac, click the minus
   button, open AltForMac again and switch on the new entry (or run
   `tccutil reset Accessibility dev.altformac.app` and reopen it).
3. The first time a command needs AppleScript, allow the Automation prompt for that Office app.

### Uninstall

Click the `⌥` menu-bar icon and choose **Uninstall AltForMac…**: it removes AltForMac's Accessibility and
Automation permissions, moves the app to the Trash and quits. With Homebrew, `brew uninstall --cask altformac`
does the same. If you drag the app to the Trash yourself, macOS keeps its permissions; clear them with
`tccutil reset All dev.altformac.app`. Full steps are in the [README](../../README.md#uninstall).

### What changed since 0.1.3

- **Key badges on the ribbon** in Excel, Word and PowerPoint. Tap Option and every tab shows its letter. Type a tab
  letter and each control of that tab shows the letters to type next (for example `M` on Merge & Center).
- **Open dropdowns get badges too.** `Option H O` opens Excel's real Format dropdown with a letter on each item,
  so `I` is on "AutoFit Column Width". AltForMac opens it with Accessibility's "show menu" action (never a press, so
  nothing is applied to your selection) and closes it before your command runs.
- Sub-menus and anything the ribbon cannot show still use the small HUD list. Prefer the list everywhere? Switch off
  **Show key badges on the ribbon** in the menu-bar menu.
- Badges are placed from the ribbon's titles and positions only. No document content is read.

### What's in it

- Sequences for Excel (206), Word (107) and PowerPoint (74).
- Key badges on the ribbon and in open dropdowns (or a small HUD list) showing which letters come next.
- Fastest-first execution: shortcut, menu bar, AppleScript, ribbon. A failed lookup shows an error badge,
  never a wrong click.
- Privacy: no networking code, no reading of workbook or document content, keystrokes are never written to disk.

### Known limitations

- Not notarized yet, so macOS shows a malware warning on first launch and Accessibility must be allowed again
  after each update. Apple Silicon only.
- Option is not skipped while you edit a cell.
- No user overrides file and no kill switch yet.

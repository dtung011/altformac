## AltForMac 0.1.1

Windows-style Alt key sequences for Excel, Word and PowerPoint on Mac. Tap Option, type `W V G`, and it
runs, including the last letter inside dropdowns that Office for Mac's own KeyTips leave out.

This release fixes the installer. The DMG now opens as a drag-to-Applications window, and the app has an
icon. The app itself behaves the same as 0.1.0.

### Download

- **Homebrew:** `brew install --cask dtung011/altformac/altformac`
- **Direct:** download `AltForMac-0.1.1.dmg` below, open it and drag AltForMac to Applications.
  The app is not notarized yet, so the first time right-click it and choose **Open**.

SHA-256 of the DMG: `28098c210175e8e255f5ed99689ec7b59a411b8a417a25a43afa4008e04ac4f4`

Requires macOS 13 (Ventura) or later. This build is for Apple Silicon.

### Set up (two minutes)

1. In Excel, Word and PowerPoint, turn **off** the Option-key KeyTips (Preferences > Accessibility),
   otherwise both react.
2. Open AltForMac. In System Settings > Privacy & Security > Accessibility, allow it.
3. The first time a command needs AppleScript, allow the Automation prompt for that Office app.

### Uninstall

Quit AltForMac, then `brew uninstall --cask altformac` (or drag the app to the Trash). Optionally remove it
from System Settings > Privacy & Security > Accessibility and Automation, and turn Office's own KeyTips back
on. Full steps are in the [README](../../README.md#uninstall).

### What changed since 0.1.0

- New app icon, also used as the disk icon.
- The DMG window shows an arrow from AltForMac to Applications.
- Each release also has `AltForMac.dmg` (same file, fixed name), used by the website's Download button.

### What's in it

- Sequences for Excel (206), Word (107) and PowerPoint (74).
- A small HUD showing what you typed and which letters come next.
- Fastest-first execution: shortcut, menu bar, AppleScript, ribbon. A failed lookup shows an error badge,
  never a wrong click.
- Privacy: no networking code, no reading of workbook or document content, keystrokes are never written to disk.

### Known limitations

- Not notarized yet; Apple Silicon only.
- Option is not skipped while you edit a cell.
- No user overrides file and no kill switch yet.
